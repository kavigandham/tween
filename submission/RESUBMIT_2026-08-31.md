## Steps in App Store Connect, in order

### 1. Business → Agreements — check FIRST
Confirm **Paid Apps** is Active. Account Holder only (Kavi); needs bank and
tax forms. Apple's rejection explicitly raised this. Without it StoreKit
vends nothing, no matter what the IAP pages say — and the paywall will fail
review again for the same reason.

### 2. Verify the products vend, before resubmitting
Install the new build from TestFlight and open Settings → Tween Pro.

- Prices shown → the store side is healthy; go to step 3.
- "Pro plans aren't available from this App Store account yet" → the store
  is still not vending. Do NOT resubmit; fix steps 1/3 first. This is the
  reviewer's exact failure, now stated honestly.
- "The App Store isn't reachable right now" → network only; retry.

### 3. Both IAPs must read "Ready to Submit"
`com.kavigandham.TweenApp.pro.lifetime` ($9.99, non-consumable) and
`com.kavigandham.TweenApp.pro.monthly` ($1.99/mo, auto-renewable). Each needs
the review screenshot (`submission/paywall-review-screenshot.png`) and review
notes. A missing review screenshot alone blocks submission.

### 4. Subtitle
Replace "Fair meetups in iMessage" with **Nobody drives the long way**.

Left as a judgment call: `metadata/keywords.txt` still contains `imessage`,
and the description still says "Works right inside iMessage". Apple flagged
only the subtitle, and both are referential compatibility uses — but they are
the same guideline if review gets stricter.

### 5. Attach BOTH IAPs and the new build, then resubmit
Version page → **Add for Review** → the draft submission → confirm **both**
products are listed (last round the draft held only "Tween Pro Monthly") →
pick the newest build → **Resubmit to App Review**.

Known ASC quirk: this attach flow does not commit under automated clicks —
the dropdown opens, the action never fires, no network call. It has to be
real clicks.

Version stays **1.0.1**: 401 was rejected, never released, so the version
string is reusable. Codemagic assigns the new build number.
